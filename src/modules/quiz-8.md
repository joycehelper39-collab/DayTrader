# Module 8 Quiz: Multi-Timeframe Analysis

**1.** In top-down analysis, the highest timeframe determines:
- Entry timing
- Trend direction
- Stop loss placement
- Position size

**2.** If daily chart shows uptrend and 4H shows pullback, you should:
- Short the pullback
- Look for long setups
- Stay flat
- Trade both directions

**3.** The execution timeframe is typically:
- Daily chart
- 15M or lower
- Weekly chart
- Monthly chart

**4.** Multi-timeframe analysis helps:
- Identify confluence
- Time entries precisely
- Both A and B
- None of the above

**5.** A setup is highest probability when:
- Only one timeframe aligns
- Multiple timeframes show confluence
- No clear direction
- Volume is low

## Answer Key

1. **B** - Highest timeframe (Daily/4H) sets trend direction
2. **B** - In uptrend, look for long setups on pullbacks
3. **B** - Execution timeframe is 15M, 5M, or 1M
4. **C** - Both confluence AND precise timing
5. **B** - Multiple timeframe alignment = higher probability
