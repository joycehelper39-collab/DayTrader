# Module 13 Quiz: Backtesting

**1.** Backtesting validates:
- Future performance
- Whether your strategy has a statistical edge
- Guaranteed profits
- Market timing

**2.** Manual backtesting involves:
- Using automated scripts
- Playing charts forward by hand
- Reading books about trading
- Using indicators only

**3.** When backtesting, you should:
- Only mark winning setups
- Mark every setup that meets your rules
- Skip losing setups
- Focus on recent data only

**4.** Backtesting helps establish:
- Guaranteed returns
- Realistic expectations for win rate and drawdown
- Perfect entry points
- Future market direction

**5.** How long should you backtest before going live?
- A few days
- At least 100 trades or several months
- One week
- It doesn't matter

## Answer Key

1. **B** - Backtesting checks for statistical edge
2. **B** - Manual = replay charts forward manually
3. **B** - Mark EVERY setup, wins AND losses
4. **B** - Sets realistic expectations for performance
5. **B** - Need 100+ trades to get statistical significance
