# Required Course Images

Due to API billing limits, images need to be sourced externally. Here's what's needed:

## Priority 1: Core Educational Diagrams

| Module | Image | Description |
|--------|-------|-------------|
| 3 | Candlestick Anatomy | Labeled diagram showing body, wick, open, close for bullish/bearish candles |
| 4 | Chart Patterns | Head & Shoulders, Double Top/Bottom, Flags |
| 5 | Support/Resistance | Zones, horizontal lines, psychological levels |
| 6 | Supply/Demand Zones | Base, departure leg, institutional order areas |
| 7 | Moving Averages | SMA/EMA lines, crossovers |
| 8 | Multi-Timeframe | D/H4/1H/15M chart stack showing top-down analysis |
| 10 | Risk/Reward | Visual showing position sizing, R:R ratio |
| 2 | Market Structure | HH/HL and LL/LH trend diagrams |

## Priority 2: Additional Visuals

- Trading desk setup
- Platform screenshots (TradingView, MetaTrader)
- Broker comparison icons
- Economic calendar example
- Journal spreadsheet screenshot

## Sourcing Options

1. **Canva** - Create custom trading diagrams
2. **TradingView** - Export chart screenshots
3. **Stock sites** - Shutterstock, Unsplash for trading photos
4. **AI** - Use credits on another account
5. **Manual** - Draw in PowerPoint/Keynote and export

## Image Specs

- Format: PNG or WebP
- Size: 1200x800 or 1024x1024
- Style: Dark theme to match course
- Files go in: `assets/images/`
